## What we do

*Please submit the Q4 forecast by 6pm.* The numbers live in a spreadsheet, the
findings in a report, the story in slides — and the reasons behind each figure
in someone's head. Every change means finding the same number in all of them.

DeepCell weaves them into **one `.deepcell` file — a kit**:

| In the kit | What it holds |
| --- | --- |
| **Spreadsheet** | The numbers and calculations, dependency-tracked |
| **Report** | The findings and conclusions, citing the numbers rather than retyping them |
| **Slides** | Ready to present or share, bound to the same figures |
| **Cheat sheet** | How you reached your conclusions — evidence, assumptions, sources |

- **Make a change, watch it flow through your work.** Move a growth rate and the
  forecast, the report's sentence, the slide's figure and the cheat sheet's
  answer all follow.
- **Follow any number back to its source.** Every edit is versioned, so you can
  see what changed, when, and why.
- **Start with your previous work.** Hand it last quarter's kit and this
  quarter's data; it rolls forward and keeps every conclusion that still holds.
- **Send any format.** Share a link that opens in a browser — no account
  needed — or export editable Excel, Word and PowerPoint.

## Build one with your AI agent

DeepCell is made for agents to read and write. Paste this into Claude Code,
Codex, Cursor or any agent with a shell:

> Read https://deepcell.net/product/for-agent.md, install both the DeepCell
> plugin and the DeepCell CLI, then help me make my first .deepcell.

Or set it up yourself:

| Your agent | Start here |
| --- | --- |
| **Claude Code** | `/plugin marketplace add deepcell-ai/deepcell-plugins` — [setup guide](https://deepcell.net/product/claude-code) |
| **Any agent with a shell** | The [plugin](https://github.com/deepcell-ai/deepcell-plugins) (Agent Plugins Spec v1.0.0) + the [`deepcell` CLI](https://pypi.org/project/deepcell-cli/) — [for-agent guide](https://deepcell.net/product/for-agent) |
| **claude.ai, ChatGPT, Manus** (no shell) | The hosted MCP connector — [connect](https://deepcell.net/product/connect) |

What the plugin contains, how to install it and example requests are in the
[plugin README](https://github.com/deepcell-ai/deepcell-plugins#readme).
